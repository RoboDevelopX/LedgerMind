How Ledgermind works

On your machine
SQLite ledger
CSV import only. Transactions, accounts and raw descriptions never leave.
Deterministic skills
15 finance tools
Summaries, subscriptions, anomalies, budgets, goals, what-if, reviews. All maths in Python.
Agent
Nemotron 3 Super
Calls and chains tools; a number guard checks every figure it writes.
Memory + privacy
Typed, editable, inspectable
FTS5 retrieval, redaction, aggregates-only payloads, a log of everything sent.
Router
Right model per job
Nano · categorise, memorySuper · agentUltra · what-if, goals, reviews
Retries, then falls back down the chain (Nemotron 3.5 Lightning as the safety net).
Nebius Token Factory serves every Nemotron model behind one OpenAI-compatible endpoint, so routing is just a model name in config.yaml.
